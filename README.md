# Dignity in Service

A short online self-check that helps store managers serve customers who are having a hard day in ways staff can't see. Based on Minton, Cabano, Blocker and Tang (2026), "Navigating Consumer Emotional Vulnerability in Services," Journal of Service Research, https://doi.org/10.1177/10946705261474275

## The files

- `index.html`: the site itself (layout, design and behavior). You rarely need to touch it.
- `content.js`: every word the site shows (audit questions, practice moments, phrase swaps, quiz cards). Edit this to change wording.
- `research-figure.jpg`: the framework figure shown under "The research behind this."

## How to change wording

1. On GitHub, click `content.js`, then the pencil icon.
2. Change the text between quotation marks. Leave the quotation marks, commas and brackets alone.
3. Click "Commit changes." The live site updates within a minute or two.
4. If the site goes blank afterward, a comma or quotation mark was lost. Open the file's History and revert the last change.

## How to update with Claude (or another AI tool)

Upload `index.html` and `content.js` to a chat, say what you want changed, and ask for the updated files back. Then on GitHub choose Add file > Upload files, drop the new files in, and commit. Files with the same name are replaced.

## Notes

- Visitors' answers are saved only in their own browser. Nothing is collected.
- The tool is a prompt for reflection, not a validated score. SLOW and the phrase swaps are derived from the article, not quoted from it.
